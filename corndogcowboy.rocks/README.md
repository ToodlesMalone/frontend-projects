# corndogcowboy.rocks

Landing page for corndogcowboy.rocks: the photo loads, pixelates, and fades into an
NES-style catching game. Scroll or swipe up and down to catch the corn dogs.

Static site, no build step. `index.html` is the whole game; `images/corndogcowboy.jpg`
is the intro photo.

Deploys on Cloudflare Pages from this repo: production branch `main`, no build command,
output directory `/`.
